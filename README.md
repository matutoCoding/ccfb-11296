# 彩绘玻璃设计预览系统

面向教堂 / 会所彩绘玻璃窗的设计与光照预览工具。TypeScript + WebGL2,自写着色器,无框架依赖。
核心能力:**按真实太阳方向,把透过彩绘玻璃的彩色光斑精确投射到室内地面和墙面上**。

## 运行

```bash
npm install
npm run dev      # 开发服务器
npm run build    # 类型检查 + 打包到 dist/
```

浏览器需支持 WebGL2(Chrome / Edge / Firefox / Safari 15+)。

## 页面

| 页面 | 功能 |
|---|---|
| 项目列表 | 项目新建 / 删除 / 复制 / 改名,localStorage 持久化,导出 / 导入 JSON |
| 图案编辑 | 多边形分块绘制(加点、拖顶点、插顶点、删顶点、整块移动/删除),铅条沿边自动生成、宽度 2–40mm 可调,导入 SVG 自动展平曲线拆成分块,Ctrl+Z 撤销 |
| 玻璃材质 | 每块玻璃独立设置颜色、透光率、肌理(平板 / 波纹 / 气泡)与肌理密度 |
| 光照预览 | 按地点(经纬度/时区/城市预设)、日期、时间计算太阳方位,彩色光斑实时投射;室内 / 室外视角切换;时间轴拖动与自动播放;截图带项目参数水印 |
| 设置 | 默认环境、纹理精度、折射扭曲强度、焦散增益、边缘柔化、铅条颜色 |

## 精度说明(光斑与窗户的几何对应)

- 太阳位置用 NOAA 算法(均时差 + 赤纬 + 时角),精度约 0.01°。
- 光斑不是贴图近似:着色器里对每个地面/墙面片元,沿太阳方向做**解析射线-窗平面求交**,
  交点落在窗洞内才采样玻璃纹理——几何上严格对应,误差只来自太阳位置算法(≪1 cm)。
- 太阳视角半径(约 0.53°)通过 4 次抖动采样柔化光斑边缘,对应真实半影。
- 波纹 / 气泡玻璃用法线贴图偏折折射方向(扭曲),并由法线场散度估计焦散增益(亮斑聚拢)。

## 代码结构

```
src/
  types.ts           数据模型(项目/图案/玻璃/环境)
  store.ts           localStorage 持久化、项目 CRUD、导入导出
  sun.ts             NOAA 太阳位置算法
  geometry.ts        多边形工具(耳切三角化、点在多边形等)
  svg.ts             SVG 解析(path 全命令含圆弧、变换矩阵、曲线展平)
  patternTexture.ts  图案纹理(颜色+透光率 / 肌理类型)与肌理法线贴图生成
  gl/shaders.ts      房间投影着色器、玻璃着色器(GLSL ES 3.00)
  gl/renderer.ts     WebGL2 渲染器、房间几何、相机
  ui/                五个页面 + DOM 工具
```

坐标约定:窗墙在 z=0 平面,室内为 z>0,x 向右(室内看窗),y 向上,单位米。
图案坐标原点在窗洞左下角。
